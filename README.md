# Habit Tracker — трекер привычек

Русскоязычный дневник для людей, которые хотят регулярно повторять полезные действия и отказываться от вредных. Каждая привычка имеет категорию, значок, цвет и цель на неделю.

## Запуск в PowerShell

Проверочная среда — Node.js 26.13.1, npm и Git. Если папка проекта уже открыта, начните с команды `npm install`. Команды ниже загружают ветку сдачи `develop`.

```powershell
git clone --branch develop https://github.com/sociald1lemma/Habit-Tracker.git HabitTracker
cd HabitTracker
npm install
node -e "const fs=require('fs');fs.writeFileSync('.env',fs.readFileSync('.env.example','utf8').replace('change-me-in-local-env',require('crypto').randomBytes(32).toString('hex')),{flag:'wx'})"
npx prisma generate
npm run dev
```

Откройте http://localhost:3000. Команда создания .env рассчитана на первый запуск. DATABASE_URL задаёт файл относительно prisma/schema.prisma. AUTH_SECRET подписывает cookie с ID профиля и сроком действия семь дней. Храните его локально.

## Демопрофили и страницы

Вход на /login по кнопке или с логином **demo** и паролем **habit-demo**. Второй вымышленный профиль **guest** использует тот же пароль. Оба доступны для демонстрации, данные одного профиля разделяются с другими посетителями этого профиля.

| Страница | Что можно сделать |
|---|---|
| / | Отметить привычку за сегодня, посмотреть прогресс и выбрать тип |
| /habits/new, /habits/[id]/edit | Создать, изменить или удалить привычку вместе с её историей |
| /calendar | Выбрать день и исправить отметки с даты создания привычки |
| /stats | Сравнить последние 7 и 30 дней, посмотреть серии и график |
| /settings | Изменить имя, дневную цель, тему, сменить профиль или выйти |

Даты рассчитываются по Новосибирску. Серия продолжается, если последняя отметка была вчера или сегодня. Недельная цель задаёт желаемую частоту. Процент в статистике считается от всех доступных для отметки дней.

## Устройство проекта

- app/ — страницы на базе App Router в Next.js 15 и серверные обработчики API. Формы настроек и входа используют серверные действия.
- components/ — интерактивные формы и список привычек на React 19 и TypeScript. Tailwind CSS и переменные темы находятся в app/style.css.
- lib/ — Prisma Client, валидация Zod, даты, подпись и проверка сессий. middleware.ts защищает маршруты.
- prisma/ — схема Prisma 6, миграции SQLite, заполненная учебная база и seed.ts.

User связан с одной записью UserSettings и несколькими Habit. Каждая запись HabitLog обозначает выполненный день. Уникальная пара (habitId, date) предотвращает двойную отметку. Снятие отметки удаляет запись, удаление привычки каскадно очищает историю.

## REST API

Запросы с телом принимают JSON. Для доступа требуется сессионная cookie.

| Метод | Маршрут | Действие | Код успеха |
|---|---|---|---|
| `GET` | `/api/habits` | Получить привычки текущего профиля | 200 |
| `POST` | `/api/habits` | Создать привычку | 201 |
| `GET` | `/api/habits/[id]` | Получить одну привычку | 200 |
| `PATCH` | `/api/habits/[id]` | Обновить переданные поля | 200 |
| `DELETE` | `/api/habits/[id]` | Удалить привычку и её отметки | 204 |
| `POST`, `PATCH` | `/api/logs` | Установить или снять отметку | 200 |

При создании привычки передайте название `title`, описание `description` (может быть пустым), категорию `category`, тип `kind` (`build` или `avoid`), недельную цель `target` (от 1 до 7), цвет `color` в формате `#RRGGBB` и значок `icon`.

Для отметки передайте `habitId`, дату `date` в формате `ГГГГ-ММ-ДД` и `done` со значением `true` или `false`. Повторный запрос с тем же состоянием сохраняет одну отметку на день либо оставляет день без отметки.

При ошибке проверки данных API возвращает 400. Для запроса без входа возвращается 401, для чужой или отсутствующей привычки — 404.

## База и проверка

prisma/dev.db уже заполнена двумя учебными профилями, 15 привычками и отметками за 14 дней. При повторном запуске скрипт заполнения сохраняет имеющиеся привычки. Для применения миграций и подготовки демо-данных:

```powershell
npx prisma migrate dev
npm run db:seed
```

Для сборки для запуска в рабочем режиме и локального запуска:

```powershell
npm run build
npm start
```

Ветка сдачи — **develop**. В main находится стартовый коммит.
